# Security Policy

## Supported version

Security fixes are maintained for the latest source version, currently 2.4.1.

## Reporting a vulnerability

Please use GitHub Security Advisories for vulnerabilities involving OAuth tokens, update packages, path traversal, local file access, proxy abuse, or remote source injection. Do not publish access tokens, signing material, exploit payloads, or private user data in a public issue.

Include the affected version, reproduction conditions, expected impact, and the smallest practical proof of concept. Reports about unavailable third-party media sites without a security impact should use a normal issue instead.
